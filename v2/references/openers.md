# 開場：主動出手的五個場景

v1 只教回應，但一半社交是你先開口。每個場景給骨架、例句、時機。cn 例句在此以繁體呈現，實際輸出時寫簡體。

## 1. 求助

骨架：先講對方的成本 → 再講你的請求 → 給死線和退路。

- hk：「想請你幫我睇 15 分鐘，唔得就出聲，我唔會拖住你。」
- cn：「想請你幫我看 15 分鐘，不方便就直說，我不會拖著。」

時機：唔好在對方趕工或開會前開。先問一句「而家講兩句方便嗎」。

## 2. 提反對

骨架：先對齊目標 → 再補風險 → 最後給備選。

- hk：「我同意要趕喺月底前出。不過按而家呢個做法，測試時間會被壓到兩日，風險喺度。要唔要我準備一個保得住時間、風險低啲嘅版本？」
- cn：「我認同月底前上線這個目標。按現在的做法測試只剩兩天，風險在這兒。要不要我準備一個保時間、風險更低的版本？」

忌：「呢個方案唔得」「我早就講過」。

## 3. 劃界

骨架：講行為 → 講影響 → 講以後點做。一次就要成文。

- hk：「每次開會前十分鐘才收到文件，我睇唔切。以後可唔可以前一晚發？真係趕嘅，我照開會，但唔會即場答。」
- cn：「每次開會前十分鐘才收到材料，我看不完。以後能不能前一晚發？實在趕，我照開會，但不會當場答。」

忌：「你哋成日都係咁」（講人格、講概括）。

## 4. 修補

骨架：認具體行為 → 講影響 → 講下次點做。

- hk：「尋日開會我打斷你，搞到你冇講完。下次你講完我先講。」
- cn：「昨天開會我打斷你，害你沒說完。下次你講完我再講。」

忌：「我份人係咁」「你唔好介意」（等於唔認）。

## 5. 拒絕前

骨架：唔好先讚後拒（會被讀成虛偽）。直接講限制，再給替代。

- hk：「呢件事我接唔到，因為手上嗰單要交。不過我可以幫你搵邊個做過。」
- cn：「這事我接不了，手上那單要交。不過我可以幫你找做過的人。」

忌：「你好叻呀，不過…」

## 6. 事後收口

一件事講完，補一句，關係才不會停在緊張狀態。

- hk：「尋日講得急，如果邊句令你唔舒服，同我講。」
- cn：「昨天說得急，哪句讓你不舒服，跟我說。」

時機：24 小時內，太遲會變成翻舊帳。

## 渠道怎麼揀

| 情況 | 渠道 |
|---|---|
| 拒絕、劃界、要留痕 | 文字（可截圖、可引用） |
| 情緒已經上來 | 語音或當面，文字容易越講越硬 |
| 對方是長輩／客戶 | 先文字預告，再電話 |
| 涉及第三方 | 私下先講，再公開對齊 |
