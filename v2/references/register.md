# register：hk 與 cn

同一個意思，兩個語境要唔同講法。判斷唔到就跟 hk。

## 對照

| 維度 | hk | cn |
|---|---|---|
| 稱呼 | 陳生、李小姐、阿姐、英文名 | X 總、X 老師、哥／姐、職銜 |
| 敬語 | 少用「您」，用「你」 | 「您」是基本，對上級幾乎必用 |
| 回執 | 群組唔興「收到」儀式；已讀不回可接受 | 「收到請回復」是常態，不回等於態度問題 |
| 錢銀 | 小額默認 AA，講明就係講明 | AA、輪請、地主之誼三套並存，要事先對規則 |
| 渠道 | WhatsApp 文字、語音、當面 | 微信、電話、飯局 |
| 時間 | 講「下晝三點」「聽日」 | 講「下午三點」「明天」，時間點常帶請示意味 |
| 人情 | 講交情、講幫過咩，但少用「人情賬」核數 | 人情可記賬，送禮、飯局、婚喪都是節點 |
| 拒絕 | 可以直接講「做唔到」，但要給原因和替代 | 先謝／先接住，原因歸自己，少評價對方 |
| 群組 | 少 @ 全體，閒聊與公事分開 | 群組是半正式場合，公開表態有分量 |
| 上下級 | 靠職級與程序，敬語較少 | 稱呼、座次、先後本身就是信息 |

## 切換信號

出現以下任何一項，切 cn：

- 用戶自己用簡體字
- 提到「領導」「單位」「體制內」「甲方」「飯局」「相親介紹人」
- 對方是大陸同事、客戶、親戚

出現以下任何一項，切 hk：

- 用戶用繁體或粵語書面（唔、咗、係、嘅）
- 提到「上司」「老細」「同事」「WhatsApp」「AA」
- 對方是香港同事、客戶、家人

## 兩個常見錯誤

- **把 cn 的「您」帶入 hk**：會顯得見外，甚至諷刺。
- **把 hk 的直接帶入 cn**：同一句話，在香港叫清楚，在大陸叫不給面子。要加一層「先接住」。

## 粵語用到幾盡

- 可以用：唔、咗、係、嘅、睇、傾、搞、嗰、呢、返（語氣）。
- 唔建議用：喎、啫、囉、㗎（太口語，書面投訴或正式郵件會失真）。
- 正式文件、書面投訴、對客戶：用標準書面繁體，只保留「唔」「係」等最少語氣。
